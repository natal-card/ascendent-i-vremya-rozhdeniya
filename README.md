# Как меняется асцендент при неточном времени рождения

Посчитайте асцендент на границах известного интервала. Возле границы знаков поправка даже на 15 минут может изменить знак.

Контрольный пример — 4 июля 1995 года. Моменты указаны в UTC. Swiss Ephemeris, Берлин 52,52° с. ш., 13,405° в. д., Лондон 51,5072° с. ш., 0,1276° з. д.

| Момент UTC | Берлин | Лондон |
|---|---|---|
| 12:30 | 202,89° · Весы | 193,69° · Весы |
| 12:45 | 205,49° · Весы | 196,33° · Весы |
| 13:00 | 208,08° · Весы | 198,97° · Весы |
| 13:15 | 210,68° · Скорпион | 201,61° · Весы |
| 13:30 | 213,27° · Скорпион | 204,24° · Весы |

Граница Весов и Скорпиона — 210°. Для Берлина окно 13:00–13:15 оставляет два возможных знака. Для Лондона в том же окне знак сохраняется. В Берлине к UTC в этот день прибавлялись два часа, в Лондоне — один.

[Рассчитать свой асцендент](https://aistre.ru/ascendent?utm_source=github&utm_medium=referral&utm_campaign=natalcard_readme_pilot&utm_content=ascendent-i-vremya-rozhdeniya). Если граница рядом, проверьте промежуточные минуты.
